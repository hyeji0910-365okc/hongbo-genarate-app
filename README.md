# 브릿지 커피 홍보물 자동 생성기

가게 사진과 가게 정보 텍스트 파일만 넣으면, 인스타그램용 정사각형 사진(로고 포함)과
인스타그램 / 네이버 블로그 / 카카오톡 공지용 홍보 문구를 한 번에 만들어 주는 자동화 도구입니다.
개발을 모르는 가게 사장님이 매주 혼자 쓸 수 있도록 만들었습니다.

## 하는 일

1. `자료` 폴더의 사진(jpg, png)을 1080 x 1080 정사각형으로 가운데 기준으로 잘라냅니다. 사진이 찌그러지지 않습니다.
2. 사진 오른쪽 아래(가장자리에서 40px 안쪽)에 반투명 흰 사각형과 함께 로고를 넣습니다. 로고 크기는 사진 가로 폭의 약 15%입니다.
3. `자료/가게 정보.txt`를 읽어 채널별 홍보 문구를 만듭니다.
   - **인스타그램용:** 감성형 / 정보형 / 이벤트형 3가지, 각각 해시태그 10개 포함, 이모지는 마지막 줄에 1개
   - **네이버 블로그용:** 1000자 안팎, 해시태그 없음
   - **카카오톡 단골 공지용:** 3줄 이내, 존댓말
4. 실행할 때마다 `완성` 폴더 안에 `2026-10-21_15시13분` 같은 새 폴더를 만들어 결과를 저장합니다. 이전 결과는 지워지지 않습니다.

문구는 사장님이 직접 쓴 글의 말투(~습니다 체, 한 줄에 한 문장, 꾸밈말 없음)에 맞춰져 있고, 외부 서비스나 API 키 없이 컴퓨터 안에서만 만들어집니다.
원본 사진은 읽기만 하고 절대 수정하지 않습니다.

## 사용 방법

자세한 설명은 [사용설명서.txt](./사용설명서.txt)를 참고하세요. 요약하면 다음과 같습니다.

1. `자료` 폴더에서 지난주 사진을 치우고, 이번 주 사진을 넣는다
2. `자료/가게 정보.txt`의 "이번 주 홍보할 것" 두 줄만 수정한다
3. `홍보물만들기.bat`을 더블클릭하거나(바탕화면 바로가기 사용 가능), 아래 명령어를 실행한다

```
python 사진변환.py
```

### 가게 정보.txt 형식

```
가게 이름: 브릿지 커피
위치: 광주 북구 비엔날레 지구
가게 특징: 직접 로스팅하는 스페셜티 커피, 조용한 1인 좌석 많음
주 고객층: 30~40대 직장인, 근처 사무실 손님

이번 주 홍보할 것:
- 신메뉴 '흑임자 라떼' 5,500원, 국산 흑임자를 직접 갈아서 넣음, 고소하고 달지 않음
- 오전 11시 이전 방문 시 아메리카노 500원 할인
```

신메뉴 줄은 메뉴 이름을 작은따옴표로 감싸고 바로 뒤에 가격을 씁니다. 혜택 줄은 끝을 "할인"으로 쓰면 문장이 가장 자연스럽습니다.

## 폴더 구조

```
홍보자동화/
├── 사진변환.py            # 메인 스크립트 (사진 변환 + 로고 + 문구 생성)
├── 홍보물만들기.bat        # 더블클릭 실행용 파일
├── 로고_투명.png          # 사진에 넣는 투명 배경 로고
├── 브릿지로고.ico         # 바탕화면 바로가기 아이콘
├── 사용설명서.txt         # 사장님용 사용설명서
├── 자료/                  # 입력: 원본 사진, 가게 정보.txt, 내 말투.txt, 로고.png
└── 완성/                  # 출력: 실행할 때마다 날짜_시각 폴더가 생김
    └── 2026-10-21_15시13분/
        ├── 20261021_01.jpg ...
        └── 홍보문구.txt
```

## 필요 환경

- Windows, Python 3.12
- [Pillow](https://pypi.org/project/Pillow/) (`pip install Pillow`)

로고 파일은 `로고_투명.png`, `로고.jpg`, `로고.png` 순서로 찾고, 어느 것도 없으면 로고 넣기만 건너뜁니다.
`가게 정보.txt`가 없거나 형식을 읽지 못하면 문구 만들기만 건너뛰고 사진은 그대로 만들어집니다.
